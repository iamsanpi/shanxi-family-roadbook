# 一路向晋 · 2026 国庆六日亲子自驾路书

面向手机的静态路书：北京—正定—忻州—雁门关—应县木塔—浑源/悬空寺—大同/云冈—北京。

## 使用

- 日期切换查看每日安排、补电、午休、餐饮和删减方案。
- 酒店候选可切换，实际含税价格手工填写并自动合计，状态仅存在本机 localStorage。
- 打印包含六天完整计划；可导出个人安排 JSON。
- 每日分段提供百度驾车导航及高德地点搜索；路线图为顺序示意，里程与时间不是实时预测。
- 来源和核验边界在页面底部；报价是查询时快照，不锁价。

## 本地运行与验证

```sh
npm ci
npm run typecheck
npm run build
npm run test:unit
python3 -m http.server 8765 --directory docs
```

GitHub Pages 发布 `feat/family-roadbook` 分支的 `/docs`。无服务器、无账号、无分析追踪、无 API key。

## 范围与隐私

2026-10-01 至 10-06（六天含往返），两成人和五岁孩子，一间房；特斯拉保守按180–220公里安排补电。住宿原目标350–500元/晚，用户随后明确按实际价格选连锁、好停车。当前主选房型报价快照五晚合计约3025元，非锁价；应县汉庭639元已实查，需确认无烟房及车位。五台山和太原不纳入本次。公开页面仅写北京出发，不含详细出发地址、携程私人行程签名或订单。
