本轮修正

雁门关、应县木塔、悬空寺、云冈石窟、大同古城全部保留为必去。忻州有值得专程安排的夜演，代州有古建，应县和浑源也各有此前漏掉的近邻景点。不能仅凭“古城类似”就删城市。

01 / DESTINATION

正定

古建 + 三国互动，不能只当中转站

隆兴寺是古建重点；赵云庙在正定，不在忻州。普通日参观较短，但今年国庆有子龙迎宾、入营击鼓和NPC互动，适合喜欢三国故事的孩子。荣国府偏影视与演艺，四塔不必全部走完。

给你们的时间预算：建议第一天下午选隆兴寺或赵云庙一组，晚间就近吃饭。含抵达休息约半天；不复制博主一整天的古城大环线。

02 / DESTINATION

忻州

夜间演艺 + 秀容书院 + 地方小吃

此前把忻州概括成普通商业古城不准确。打铁花是单独保留一晚的理由；白天可选秀容书院，晚间吃蒸肉、羊杂、锅盔等。是否值得住，取决于你们是否想看演艺。

给你们的时间预算：建议下午休息，傍晚短段古城 + 一场打铁花。不要把博主4km、6–8小时的完整路线压成两小时。

代县 / 雁门关

必去关隘 + 可选代州古建

雁门关必须保留。代州也不只是住宿点：边靖楼、文庙、阿育王塔有独立游览价值。但六天里不必为凑齐这些点强加一晚。

给你们的时间预算：雁门关先按3–4小时预算，含摆渡、台阶、休息与排队；北进北出亲子样本约2.5小时。若当天继续应县，代州古城只作有余力的备选。

04 / DESTINATION

应县

木塔必去，净土寺是此前遗漏的近邻

木塔看木构、斗拱、匾额和一层佛像；净土寺看藻井、天宫楼阁。两者是不同看点，不应只到木塔门口拍照就走。

给你们的时间预算：木塔建议留1–1.5小时起，认真讲解可更久；净土寺另留30–60分钟，排队和转场另计。雁门关当天若到得晚，木塔可移次晨，不能赶闭园。

浑源 / 悬空寺

悬空寺必去，永安寺壁画值得做备选

悬空寺之外，永安寺壁画、圆觉寺塔让浑源古城有独立内容；2026新增《何以悬空寺》演出。不能把所有寺庙和夜演都塞进一次中转。

给你们的时间预算：悬空寺按半天保护时间，登临取决于预约与现场秩序。永安寺约1小时为可选预算；若同天还要木塔并前往大同，就不再加古城全套。

06 / DESTINATION

大同古城

白天看辽金建筑，夜晚逛城墙与街巷

华严寺、善化寺值得从“古城散步”里单独拿出来。华严寺的薄伽教藏殿等室内原作适合较早看；晚上选鼓楼、华严寺广场或一小段城墙，不走全圈。

给你们的时间预算：华严寺建议1.5–2小时；善化寺约1小时作为备选。夜游60–90分钟，配晚餐。云冈当天午休后若太晚，不勉强赶室内参观。

云冈石窟

必去半日重点，讲解要适合五岁孩子

重点洞窟配简短故事，避免逐窟长讲解。亲子样本提示主路推车与进窟不同，需要交替步行；带水与简餐，游览后安排休息。

TIME TRADE-OFF

六天的矛盾在哪里？

保留正定和忻州夜演时，可以形成下方候选顺序；最难的是第三、四天，不能同时承诺代州全套、木塔深讲、浑源夜演和充足午休。

候选顺序，尚未定稿：北京 → 正定 → 忻州 → 雁门关 → 应县 → 悬空寺 → 大同 → 北京。

日期重点 / 候选过夜
10/1北京到正定；选一组景点，住正定
10/2正定到忻州；下午休息、晚间铁花，住忻州
10/3雁门关后前往应县；木塔看抵达时间，住应县待查
10/4木塔若未游则先补；悬空寺以预约时段为约束，住大同
10/5云冈半天、午休、大同古城短段，续住大同
10/6视返程预算安排古城白天看点，返回北京

不能称它已是最佳路线：若木塔移到第四天，会挤压悬空寺；若悬空寺只能抢到早场，又会影响应县过夜方案。大同寺庙也需要白天。应先核对入口导航、预约时段和应县住宿，再决定正定或忻州留哪一个、留多长。

正定早出发、游雁门关后前往应县并非先验不可行，但这一整天的实际驾驶、180–220km补电、午餐及景区排队尚未完成验证。不能用普通日地图时间替代国庆带娃体验。

以上新增景点是选项，不是新的全打卡任务。五台山、太原仍不加入本次。酒店以实际价、连锁和好停车优先，没有替换或预订新酒店。
