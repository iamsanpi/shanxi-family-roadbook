PLAN B

延误时怎么减，已经想好。

  • 木塔不删。10/3晚到应县，改10/4早上；悬空寺需约上午后段或午后。已锁早场则要先调整，不能当天硬赶。
  • 午休不拿来凑景点。先减净土寺、永安寺、华严寺等可选项。
  • 登临不强求。悬空寺没登临票或孩子怕高，仍可按入园规则看建筑外观。
  • 返程不补打卡。10/6早餐后离开，把余量留给堵车与充电。

极端拥堵、天气停开等情况下，六天与全部必去可能无法兼得，需要调整天数或日期；不以赶夜路弥补。
